# Unity: нейросетевой 3D-монстр

Это готовые Assets для проекта **Unity 6, 3D Built-in Render Pipeline**. Сам редактор Unity на этой машине не установлен: компиляция и Play Mode в Unity пока не проверены. GLB, скелет, веса и анимация проверены независимо и в работающем Godot-просмотрщике. Это расширение проекта, без изменения ядра Unity.

1. Создай пустой 3D-проект с Built-in Render Pipeline.
2. Скопируй папку `unity/Assets/SpookyNeuro` в его `Assets`. В архиве `artifacts/3d/spookyneuro-unity.zip` она уже лежит с правильным префиксом `Assets/`.
3. Дождись импорта. Выбери **SpookyNeuro → Create 3D Demo**.
4. Сохрани созданную дополнительную сцену, нажми **Play**. ПКМ вращает камеру, колесо приближает, Space включает походку / позу покоя, M включает изменение поверхности.

В `Models/creature.spooky.json` находятся настоящая сгенерированная геометрия, окраска, 19 костей, по четыре веса на вершину и blend shape `DensityShift`. `NeuralCreature` строит обычный `SkinnedMeshRenderer` и воспроизводит походку. Материал `SpookyNeuro/VertexLit` использует цвет вершин и освещение; шейдер рассчитан на Built-in. Для URP потребуется заменить материал на совместимый шейдер с цветом вершин — геометрию и скелет менять не нужно.

В игре не требуется запускать Python или загружать нейросеть. Повторная генерация выполняется внешним инструментом; после неё замени JSON в `Models`. Привязка автоматическая, с человекоподобным A-pose-шаблоном, а не универсальный авториг произвольной анатомии. Деформации пока экспериментальные: пальцы объединены с кистью, нет IK, ретаргетинга Humanoid и физики мягкого тела.

Для своего префаба достаточно добавить `NeuralCreature` на пустой объект, назначить `source` и `material`. Сборка меша происходит в `Start`, временный Mesh освобождается в `OnDestroy`. GLB с той же геометрией и записанным клипом `CreepWalk` находится в `artifacts/3d/generated/creature.glb`; для его прямого импорта в Unity понадобится отдельный glTF-импортёр. JSON-вариант обходится без него.
