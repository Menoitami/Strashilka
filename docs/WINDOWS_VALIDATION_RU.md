# Проверка Windows-сборки

Историческая проверка Windows-порта до добавления анатомических мутаций,
20 октября 2026, на основе `121b158`. Актуальные изменения и новые прогоны
описаны в [NEURAL_ENTITY_RU.md](NEURAL_ENTITY_RU.md).

## Окружение

- Windows x86_64, NVIDIA GeForce RTX 4070 SUPER, 12 ГБ VRAM, драйвер 617.14.
- Godot 4.7.2, Compatibility / OpenGL 3.3, окно 1280×720.
- Python 3.12, PyTorch 2.11.0+cu128, torchvision 0.26.0+cu128.
- SD 1.5 + LCM + локальная body-horror LoRA + TripoSR.
- Веса загружены по ревизиям из `src/spookyneuro/model_assets.py`.

## Проверки

- 42 Python-теста пройдены; Ruff не нашёл ошибок.
- Godot: `rig_check.gd`, `volume_check.gd`, `room_3d_check.gd` пройдены.
- Экспортированный EXE загрузил исходную модель и прошёл запуск без ИИ.
- Служебный экспорт настроек через обычную точку входа EXE проверен.
- Окружение установлено отдельно внутри `dist/SpookyNeuro-Windows-x86_64`.
- `Start SpookyNeuro.cmd` из этой папки прогрел модели, получил настоящую первую
  форму и открыл экспортированный плеер; далее принимались новые пакеты.
- Закрытие плеера штатно завершило worker: статус «Поток остановлен».
- `verify_live.py` подтвердил непрерывность пакетов #7 → #8: одинаковые стыкуемые
  геометрия и bind-данные, новые seed, форма, цвет и нормали.
- ZIP проверен по CRC, содержит манифест SHA-256; хеш самого архива лежит рядом.

## Измеренный прогон

45 секунд сцены с движением камеры и работающим ИИ, стандартными настройками,
одним автоматическим PNG-снимком и ограничением 60 FPS:

| Метрика | Значение |
| --- | --- |
| Показанные состояния тела, включая первое | 7 |
| Принятые обновления лица | 23 |
| Обновления лица во время перехода тела | 19 |
| Средний FPS | 53,17 |
| p95 времени кадра | 17,062 мс |
| Первая генерация тела после загрузки моделей | 4,14 с |
| Последующие генерации тела | 2,828–2,968 с |
| Дополнительные лицевые проходы | 0,906–1,172 с |
| Пройденное монстром расстояние | около 10 м |

Средний FPS включает начальные задержки сцены; это короткий функциональный
прогон, а не гарантия стабильных 60 FPS на всех системах. Новая нейросетевая
форма по-прежнему получается раз в несколько секунд и интерполируется в игре.

Локальные подробности: `artifacts/windows-packaged-live.json`,
`artifacts/windows-packaged-launch.log`, `artifacts/windows-package-setup.log`,
`artifacts/windows-continuity.log`, `artifacts/windows-pytest.log`.

`artifacts/windows-build-preview.png` — отдельный снимок экспортированного
плеера при воспроизведении сохранённого нейросетевого пакета #8 без новой
генерации и без интерфейса; это не изображение предложенных новых эффектов.

## Состав поставки

После разделения поставок архив находится в
`dist/windows/SpookyNeuro-Windows-x86_64.zip`. Он содержит EXE, PCK, исходные модели,
локальный адаптер, Python-код, закреплённый код TripoSR, uv и установочные скрипты.
Python-окружение, крупные общие веса и тестовые сессии в архив не входят.
Окружение прогона выше находится в прежней папке `dist/SpookyNeuro-Windows-x86_64`.
В новой распакованной папке его создаст `Start SpookyNeuro.cmd`.
Linux-пакет находится отдельно в `dist/linux/SpookyNeuro-Arch-x86_64.zip`;
Windows-архив не содержит shell-скриптов Linux.
